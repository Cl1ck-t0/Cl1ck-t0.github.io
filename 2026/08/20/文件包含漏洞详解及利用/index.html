文件包含漏洞

一、基础知识

1.什么是文件包含漏洞

1.1 基本概念

文件包含漏洞是指应用程序在引入文件时，用户能够控制包含的文件路径，导致服务器执行了非预期的文件内容。

1.2 为什么会存在文件包含漏洞？

原因 说明
动态包含 开发者根据用户输入动态决定包含哪个文件
路径可控 用户输入直接拼接到文件路径中
缺乏过滤 没有对用户输入进行安全验证
配置不当 allow_url_include = On 允许远程包含

2.PHP 中常见的文件包含函数

2.1 函数对比

函数 包含失败时 执行代码 可包含远程文件（allow_url_include=On）
include() 产生警告，脚本继续执行 ✅ ✅
include_once() 产生警告，脚本继续执行 ✅（仅一次） ✅
require() 产生致命错误，脚本停止 ✅ ✅
require_once() 产生致命错误，脚本停止 ✅（仅一次） ✅
include() + 远程 可包含远程文件 ✅ ✅

6.Session Upload Progress 详解

6.1 什么是 Session Upload Progress？

PHP 5.4+ 的特性：上传文件时，如果请求包含特定字段，PHP 自动将上传进度保存到 Session。

6.2 触发条件

条件 说明
session.upload_progress.enabled = On 启用上传进度（默认开启）
POST 请求包含 PHP_SESSION_UPLOAD_PROGRESS 字段 触发写入
同时上传文件（$_FILES） 必须有文件上传
Cookie 中包含 PHPSESSID 指定Session ID
